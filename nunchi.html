눈치코치

Overview

장례식, 결혼식, 회식, 직장처럼 처음 겪는 자리에서는 어떻게 행동해야 할지 막막합니다. 눈치코치는 이런 상황을 미리 연습해 보는 예절 가이드 앱과 웹 서비스입니다.

정답을 정해 주기보다, 같은 상황에서 다른 사람들이 어떤 선택을 했는지 비율로 보여 줍니다. 사용자는 그 결과를 보며 스스로 판단해 볼 수 있습니다.

Design Concept

Problem

예절을 배울 곳이 마땅치 않습니다

예절을 몰라 실수하면 관계가 어색해지지만, 따로 가르쳐 주는 곳은 드뭅니다. 글로 읽기만 해서는 실제 상황에서 떠올리기 어렵습니다.

Insight

다른 사람의 선택을 보여 줍니다

예를 들어 "78%가 두 손으로 잔을 받았습니다"처럼 비율로 보여 주면 긴 설명 없이도 이해하기 쉽습니다.

Solution

상황을 골라 연습합니다

상황을 보고 선택지를 고른 뒤, 다른 사람들의 선택 비율을 확인합니다. 여러 상황을 반복해 연습할 수 있습니다.

Scope

앱과 웹

앱에서는 짧은 시뮬레이션과 커뮤니티를, 웹 랜딩 페이지에서는 서비스 소개와 다운로드 안내를 맡습니다.

Brand Color

밝고 친근한 오렌지를 메인 색으로 썼습니다. 예절 서비스가 딱딱해 보이지 않고 가볍게 연습하는 느낌을 주려고 했습니다.

Simulation Flow

시뮬레이션은 세 단계로 진행됩니다.

상황 제시
실제 일어날 법한 사회적 장면이 카드 형식으로 주어집니다
→
선택지 고르기
세 가지 반응 중 자신이라면 어떻게 할지 선택합니다
→
결과 확인
실제 사람들의 선택 비율과 그 결과를 수치로 확인합니다
장례식
조문 순서, 복장, 위로의 말
결혼식
축의금 금액, 부조 방법, 하객 예절까지
회식
잔 받는 법, 자리 배치, 음주 거절
직장
명함 교환, 업무 대화, 상사와 대화하는 법
경조사
승진 축하, 출산 선물, 경조사 메시지 작성법
병문안
무엇을 가져가야 할지, 어떤 말이 위로가 되는지
서비스 개요
웹, 인터랙션, 모바일 앱

Interaction Layer

웹 랜딩 페이지에 카메라 손 인식 기능을 더한 버전입니다. Three.js 배경, MediaPipe 손 인식, 상황별 테마 전환으로 구성했습니다.

인터랙션 모드를 켜면 카메라가 손 제스처를 인식합니다. 결혼식, 장례식, 회식, 직장 테마를 고르면 색, 카드 애니메이션, 배경이 함께 바뀝니다.

Visit Interaction ↗

Three.js Atmospheric Background

페이지 뒤에 깔린 배경 캔버스입니다. 테마를 바꾸면 배경 색과 조명도 함께 바뀝니다.

MediaPipe Hand Tracking

카메라로 손 제스처를 인식합니다. 화면 구석에 카메라 화면과 제스처 안내가 표시되고, 버튼이나 제스처로 인터랙션 모드를 켜고 끕니다.

상황별 테마 시스템

결혼식, 장례식, 회식, 직장 4개 테마가 있습니다. 스와이프나 버튼으로 테마를 바꿉니다.

다크모드와 테마 독립 구조

다크모드와 상황 테마를 따로 켜고 끌 수 있습니다. 둘이 겹칠 때는 CSS 우선순위를 조정해 테마 색이 먼저 적용되게 했습니다.
